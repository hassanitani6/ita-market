# Font licences

Every font file in `fonts/` is licensed under the SIL Open Font License 1.1; the licence text for each family is in
this folder.

Four engraving styles are offered under the names of fonts that can't be redistributed (Apricot, Bodoni MT,
Telegraf, TT Drugs). The pages use the real font when it is installed on the device viewing them, and otherwise show
a similar free stand-in: Sacramento, Bodoni Moda, Outfit and Jost respectively.
